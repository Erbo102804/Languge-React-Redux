# EduHub — образовательная платформа

Учебный проект на **React + Redux Toolkit + React Router**: одностраничное
SPA-приложение для управления курсами, расписанием и записями студентов
с авторизацией, личным кабинетом и чатом с преподавателем.

## Описание проекта

**EduHub** — это веб-приложение учебной онлайн-школы. Платформа решает
задачи:

- показать каталог курсов с описаниями, ценами и преподавателями;
- дать пользователю записаться на курс и видеть личное расписание;
- предоставить студенту возможность общаться с преподавателем в чате;
- управлять курсами (CRUD) через интерфейс — для авторизованных
  пользователей;
- показывать новости школы, состав преподавателей и студентов.

Проект построен как **полностью клиентское SPA** — без бэкенда. Данные
курсов, новостей и преподавателей загружаются из статических JSON-файлов,
а состояние авторизации, записи на курсы и чат-сообщения сохраняются в
`localStorage`.

## Возможности (фичи)

### Авторизация
- регистрация нового пользователя (имя, email, пароль с подтверждением);
- вход с проверкой email/пароля;
- выход из аккаунта;
- состояние авторизации сохраняется в `localStorage` и восстанавливается
  при перезагрузке страницы.

### Каталог курсов
- список всех курсов с карточками: название, уровень, цена в сомах,
  рейтинг, длительность, число студентов;
- детальная страница курса с полным описанием, программой («Что вы
  изучите»), расписанием и преподавателем;
- индикатор загрузки на время эмулированной задержки (`createAsyncThunk`);
- обработка ошибок загрузки.

### Запись на курс
- кнопка **«Записаться на курс»** на детальной странице:
  - неавторизованный пользователь — редирект на `/login` + тост
    «Войдите в аккаунт, чтобы записаться»;
  - авторизованный пользователь — запись фиксируется, показывается
    тост-уведомление, кнопка превращается в бейдж «✓ Вы записаны» с
    кнопками «Личный кабинет» и «Отписаться»;
- каждому курсу детерминированно назначается слот расписания
  (день + время) по `course.id` через `getScheduleSlot()`;
- записи сохраняются в `localStorage` и привязаны к `userId`.

### Личный кабинет (`/profile`)
- аватар-инициал, имя и email пользователя;
- счётчики: количество курсов и общая стоимость в сомах;
- сетка карточек **«Мои курсы»** с днём, временем, преподавателем,
  длительностью и кнопкой «Отписаться»;
- для неавторизованных — автоматический редирект на `/login`.

### Расписание (`/schedule`)
- секция **«Моё расписание»** — таблица курсов текущего пользователя,
  отсортированная по дню и времени, со ссылками на детальную страницу;
- общее расписание школы — справочная таблица занятий.

### Чат с преподавателем
- плавающая кнопка **«💬 Написать преподавателю»** в правом нижнем углу
  на детальной странице курса;
- раскрывается в окно-чат в стиле виджетов поддержки:
  - аватар + имя преподавателя, индикатор «онлайн», название курса;
  - история сообщений: студент справа, преподаватель слева,
    с «хвостиками» у пузырьков;
  - индикатор «печатает…» (три анимированные точки);
  - поле ввода + кнопка отправки;
- авто-ответ преподавателя через ~1 секунду; реплика выбирается по
  ключевым словам в сообщении (приветствие, цена, расписание, программа,
  сертификат, благодарность) либо случайно из набора заготовок;
- бейдж со счётчиком сообщений на кнопке;
- история сохраняется в `localStorage` по паре `userId + courseId`,
  чужому пользователю не видна;
- для гостей — заглушка с предложением войти в аккаунт.

### CRUD курсов (только для авторизованных)
- кнопка **«+ Добавить курс»** на странице `/courses`;
- иконки ✏️ и 🗑️ на карточках курсов и кнопки «Редактировать» / «Удалить»
  на детальной странице;
- модальная форма добавления/редактирования с валидацией полей;
- модальное подтверждение удаления;
- для гостей все эти элементы скрыты.

### Прочие страницы
- **Главная (`/`)** — hero-блок со статистикой, топ-3 курсов, лента
  новостей, преподаватели.
- **Студенты (`/students`)** — список зарегистрированных студентов.
- **О нас (`/about`)** — информация о школе.

### Уведомления (Toast)
- глобальная очередь тост-сообщений в правом верхнем углу;
- три типа: `success` (зелёный), `info` (синий), `error` (красный);
- авто-скрытие через 3.5 с + кнопка ручного закрытия;
- используется при записи/отписке, попытке записи без авторизации и т.п.

## Архитектура Redux

Store собран через `configureStore` из 8 slice'ов:

| Slice | Хранит | Сохраняется |
|---|---|---|
| `auth` | текущий пользователь, ошибки логина | `localStorage` (`user`, `users`) |
| `courses` | список курсов, текущий курс, loading/error | в памяти |
| `students` | студенты | в памяти |
| `teachers` | преподаватели | в памяти |
| `news` | новости | в памяти |
| `enrollments` | записи `[{userId, courseId, day, time, …}]` | `localStorage` (`enrollments`) |
| `notifications` | очередь тостов | в памяти |
| `chat` | сообщения `[{userId, courseId, role, text, ts}]` | `localStorage` (`chat_messages`) |

Для асинхронных операций используется `createAsyncThunk`:

- `fetchCourses` — загрузка из `/data/courses.json` с задержкой 1.5 с;
- `fetchCourseById` — ищет в кеше, иначе тянет JSON;
- аналогично для `students`, `teachers`, `news`.

Селекторы:

- `selectIsEnrolled(userId, courseId)` — записан ли пользователь;
- `selectUserEnrollments(userId)` — курсы пользователя;
- `selectChat(userId, courseId)` — сообщения чата.

## Источники данных

Статические JSON-файлы лежат в `public/data/` и грузятся через `fetch`:

- **`courses.json`** — 6 курсов: `id`, `title`, `description`,
  `fullDescription`, `price`, `duration`, `level`, `image`, `instructor`,
  `rating`, `students`, `lessons`, `topics[]`.
- **`news.json`** — новости школы: `id`, `title`, `summary`, `content`,
  `date`, `author`, `image`, `category`.
- **`teachers.json`** — преподаватели: `id`, `name`, `position`, `bio`,
  `avatar`, `courses`, `students`, `rating`.

Слот расписания для курса генерируется детерминированно из `course.id`
(функция `getScheduleSlot` в `enrollmentsSlice`), поэтому один и тот же
курс всегда показывает одинаковый день и время в карточке курса,
в общем расписании и в личном кабинете.

## Установка и запуск

Требуется **Node.js ≥ 18**.

```bash
git clone https://github.com/Erbo102804/Languge-React-Redux.git
cd Languge-React-Redux
npm install
npm run dev
```

Vite поднимется на `http://localhost:5173`. HMR работает из коробки.

Для продакшен-сборки:

```bash
npm run build      # бандл в dist/
npm run preview    # предпросмотр собранной версии
```

## Сценарии использования

### Новый пользователь записывается на курс

1. Открывает `/courses`, кликает по карточке.
2. На детальной странице нажимает «Записаться на курс».
3. Редирект на `/login` + тост «Войдите в аккаунт».
4. Регистрируется через `/register` или входит.
5. Возвращается на курс, снова жмёт «Записаться на курс».
6. Появляется тост «Вы записались на курс «…». Занятия: Вторник,
   11:30 - 13:30», кнопка превращается в бейдж «✓ Вы записаны».
7. В шапке кликает по своему имени → попадает в `/profile` со списком
   своих курсов.
8. В `/schedule` сверху появляется секция «Моё расписание» с курсом.

### Студент задаёт вопрос преподавателю

1. На детальной странице курса в правом нижнем углу — кнопка
   «💬 Написать преподавателю».
2. Открывается чат-окно с приветствием преподавателя.
3. Студент пишет сообщение, например: «Сколько стоит курс?»
4. Сообщение появляется справа, под ним — индикатор «печатает…»
5. Через секунду слева приходит ответ преподавателя по теме.
6. История сохраняется: после перезагрузки страницы все сообщения
   восстанавливаются, на кнопке появляется бейдж со счётчиком.

### Администратор управляет курсами

1. Входит в аккаунт.
2. На `/courses` появляются кнопки «+ Добавить курс», ✏️, 🗑️.
3. Может создать новый курс, отредактировать существующий или удалить
   (с модальным подтверждением).

## Хранение данных

В `localStorage` хранятся 4 ключа:

| Ключ | Что лежит |
|---|---|
| `users` | массив зарегистрированных пользователей |
| `user` | текущий вошедший пользователь |
| `enrollments` | все записи на курсы (все пользователи) |
| `chat_messages` | все сообщения чатов |

Записи и сообщения других пользователей не видны — фильтрация
происходит по `userId` через селекторы.

После logout пользователь удаляется из `user`, но записи и сообщения
остаются — при повторном входе он увидит свои курсы и чаты обратно.

## Стиль и дизайн

- тёмная тема с фиолетово-синим градиентом (`#667eea → #764ba2`);
- закруглённые углы, мягкие тени, плавные `transition`;
- адаптивная вёрстка через media-queries (мобильное меню-бургер
  в шапке, перестроение сеток курсов);
- CSS-only анимации: тост, чат-окно, индикатор «печатает», hover-эффекты.

Иконки — emoji (`👤`, `💬`, `✓`, `★`, `🎓` и т.д.) для простоты и
кросс-платформенности.

## Развитие проекта

Возможные направления:

- реальный бэкенд (Express / Nest / Firebase) вместо `localStorage`;
